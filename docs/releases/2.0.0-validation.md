## Reproduce

From a development checkout:

```bash
poetry env use python3.11
poetry install
poetry run pytest -q
poetry run ruff check .
poetry build
poetry run python examples/local_planner_client.py
poetry run python examples/planner_modes_client.py
python3 ~/.agents/skills/skill-conflict-checker/scripts/check_skill_against_agents.py .agents/skills/create-client/SKILL.md
sha256sum dist/okama_mcp-2.0.0-py3-none-any.whl dist/okama_mcp-2.0.0.tar.gz
```

For clean acceptance create a fresh Poetry project under `tmp/`, Python
>=3.11,<3.12, with a file dependency on the MCP wheel and `fastmcp = "4.0.11"`.
Do not add a Planner or okama file dependency: MCP metadata requires
`okama-planner[reports]>=0.4.0,<0.5.0` and `okama>=4.0.0`, both resolved from PyPI.
Use `poetry --no-cache install` to avoid stale index responses immediately after
publication. The checked clean project is `tmp/pypi-pair-clean/`.
Run this repository's `examples/local_planner_client.py` with that clean environment's
Python, without PYTHONPATH overrides. It uses installed packages and synthetic files.
The local artifact digest manifest is `tmp/release-candidate-manifest.json`; it is
not embedded in its own archive. Generated logs/data are also under `tmp/`.
