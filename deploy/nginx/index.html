okama-mcp

A Model Context Protocol (MCP) server that exposes the okama investment-portfolio toolkit to AI assistants — Claude Desktop, Claude Code, Cursor, Codex, and any other MCP-compatible client.

Free and open source. Run it locally or on your own server. Local client-registry tools and Excel exports require a configured stdio installation.

What you can ask

With okama-mcp connected, you can ask an AI things like:

  • "Backtest a portfolio of 30% gold and 70% real estate over the last 15 years."
  • "Run a Monte Carlo retirement forecast withdrawing $1,000/month indexed to inflation over 25 years."
  • "Build a plan: contribute $1,000/month for 20 years into a 70/30 portfolio, then withdraw $6,000/month indexed to inflation for 25 years — what are the odds it lasts?"
  • "What's the tangency portfolio of SPY, BND, and GLD with a 3% risk-free rate?"
  • "Plot the efficient frontier of SPY, BND, and GLD."
  • "Show the five MOEX-listed BPIFs with the longest price histories."

The AI calls the MCP tools, which call okama directly — no Python code needed on your side.

Charts

Version 2.0.0 includes okama Planner household forecasts. Local installations can configure client registration and Excel reports. Client records and private presentation files stay locally configured; the public HTTP service has no local registry access. Install & run locally

# run straight from PyPI — no clone needed
uvx okama-mcp stdio

Requires Python ≥ 3.11. Easiest with uv or pipx; plain pip and source installs (git + Poetry) are covered in the README.

Full setup guide and client configurations (Claude Desktop, Claude Code, Cursor, Codex): see the README on GitHub.

Self-host on your server

Share one instance across your MCP clients with the streamable-http transport: 

okama-mcp http --host 127.0.0.1 --port 8765 --path /mcp

Ready-made nginx and systemd examples are in the deploy/ directory.
